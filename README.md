# ربات کپی محتوای تلگرام برای Railway.app

این ربات با استفاده از API کاربر تلگرام (User Client) و ربات، محتوای کانال مبدأ را بدون نیاز به دسترسی ادمین در آن کانال، کپی کرده و در کانال مقصد که ربات ادمین است منتشر می‌کند.

## ویژگی‌ها

- ✅ کپی محتوا از کانال مبدأ بدون دسترسی ادمین
- ✅ حذف ایموجی‌های پرمیوم و تبدیل به نسخه عادی
- ✅ کپی بدون فوروارد (بدون نمایش "Forwarded from")
- ✅ تغییر تامنیل ویدیوها
- ✅ سیستم صف برای پردازش پیام‌ها
- ✅ جایگزینی کلمات در متن پیام‌ها
- ✅ پشتیبانی از عکس، ویدیو، فایل، صوت و ویس

## راه‌اندازی روی Railway.app

### 1. دریافت API_ID و API_HASH

1. به https://my.telegram.org بروید
2. با شماره تلگرام خود وارد شوید
3. به بخش "API development tools" بروید
4. یک اپلیکیشن جدید بسازید
5. `API_ID` و `API_HASH` را یادداشت کنید

### 2. ساخت ربات تلگرام

- با @BotFather صحبت کنید و یک ربات جدید بسازید
- توکن ربات را دریافت کنید

### 3. تنظیم کانال‌ها

- اکانت کاربری خود را به کانال مبدا اضافه کنید (به عنوان عضو عادی)
- ربات را به کانال مقصد اضافه کنید (به عنوان ادمین)
- آیدی کانال‌ها را دریافت کنید (با @userinfobot یا @getidsbot)

### 4. دریافت SESSION_STRING (اختیاری اما توصیه شده)

برای اجرای پایدار روی Railway، بهتر است SESSION_STRING را تنظیم کنید:

```python
from pyrogram import Client

async def generate_session():
    api_id = int(input("Enter API_ID: "))
    api_hash = input("Enter API_HASH: ")
    
    async with Client("temp_session", api_id=api_id, api_hash=api_hash) as app:
        session_string = await app.export_session_string()
        print(f"\nYour Session String:\n{session_string}")

if __name__ == "__main__":
    import asyncio
    asyncio.run(generate_session())
```

### 5. تنظیم متغیرهای محیطی در Railway

| متغیر | توضیح | مثال |
|-------|-------|------|
| `API_ID` | API ID اکانت تلگرام شما | `12345678` |
| `API_HASH` | API Hash اکانت تلگرام شما | `abcdef1234567890` |
| `BOT_TOKEN` | توکن ربات از BotFather | `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz` |
| `SOURCE_CHANNEL_ID` | آیدی کانال مبدا | `-1001234567890` |
| `DEST_CHANNEL_ID` | آیدی کانال مقصد | `-1009876543210` |
| `ADMIN_USER_IDS` | آیدی ادمین‌ها (جدا شده با کاما) | `123456789,987654321` |
| `SESSION_STRING` | (اختیاری) Session String برای User Client | حاصل از اسکریپت بالا |
| `DEFAULT_THUMBNAIL_URL` | (اختیاری) URL تامنیل پیش‌فرض | `https://example.com/thumb.jpg` |

### 6. دستورات ربات

- `/start` - شروع ربات و نمایش راهنما
- `/replace قدیمی جدید` - تنظیم جایگزینی کلمه
- `/replacements` - نمایش لیست کلمات جایگزین
- `/clear` - پاک کردن همه کلمات جایگزین
- `/status` - نمایش وضعیت ربات

## نحوه کارکرد

1. ربات با استفاده از User Client (که نیاز به API_ID و API_HASH دارد) به کانال مبدا متصل می‌شود
2. پیام‌های جدید کانال مبدا را تشخیص می‌دهد
3. محتوا را دانلود کرده و پردازش می‌کند:
   - جایگزینی کلمات در متن
   - حذف ایموجی‌های پرمیوم
   - تغییر تامنیل (در صورت تنظیم)
4. محتوا را در کانال مقصد به صورت مستقیم (نه فوروارد) ارسال می‌کند

## نکات مهم

- ربات باید در کانال مقصد **ادمین** باشد
- برای کانال مبدا نیازی به دسترسی ادمین نیست (اکانت کاربری باید عضو باشد)
- آیدی کانال‌ها باید با `-100` شروع شود
- برای اجرای پایدار روی Railway، حتماً SESSION_STRING را تنظیم کنید
- اگر SESSION_STRING تنظیم نشود، ربات در هر بار اجرا نیاز به لاگین دارد

## مشکلات رایج

### ربات پیام‌ها را دریافت نمی‌کند:
- مطمئن شوید اکانت کاربری به کانال مبدا اضافه شده است
- آیدی کانال را درست وارد کرده‌اید (با -100 شروع شود)
- API_ID و API_HASH را درست وارد کرده‌اید

### پیام‌ها کپی نمی‌شوند:
- بررسی کنید ربات در کانال مقصد ادمین است
- متغیرهای محیطی را چک کنید
- لاگ‌های Railway را بررسی کنید

### خطا در Railway:
- لاگ‌ها را در پنل Railway بررسی کنید
- مطمئن شوید تمام متغیرهای محیطی تنظیم شده‌اند
- SESSION_STRING را تنظیم کنید تا مشکل لاگین حل شود
